VA - VHA - NOP Executive Action Tracker

A SharePoint, Power Apps, Power Automate, and Power BI solution developed to modernize the National Oncology Program (NOP) Executive Admin team’s action tracking process by reducing manual effort, improving data quality, automating daily reporting, and surfacing task performance metrics for leadership.

Back to Projects

Description

This project modernized the NOP Executive Admin team’s action tracking process by replacing a manual Excel-based tracker with an integrated solution built on SharePoint, Power Apps, Power Automate, and Power BI. The original tracker was used to manage administrative tasks, assign ownership, and provide daily rollups to leadership, but it required fully manual data entry, lacked validation and Global Address List connectivity, and depended on manually composed daily email reports. The redesigned solution introduced a SharePoint List with validated and calculated fields, a Power App for intuitive task entry and editing, automated email and Teams messaging, daily Power Automate roll-up reports, and a Power BI dashboard for KPI monitoring such as item counts, completion time, and late-item trends. The updated SharePoint page also embedded the dashboard while preserving familiar navigation for end users, and the user guide documented workflows for adding, editing, assigning, filtering, and monitoring action items in the new system.
