VA - VHA - EXCLAIM Executive Admin Dashboard

A custom Power BI and Microsoft 365-based dashboard suite designed to support executive visibility, operational tracking, and implementation monitoring for a nationwide VA program.

Back to Projects

Description

This project supported the nationwide rollout of a program to improve cancer treatment efficacy by utilizing genetic testing to narrow the selection of treatments among alternatives. We developed registration and scheduling tools using Microsoft O365 apps (Outlook, Forms, SharePoint, Teams, Power Apps), integrated via Power Automate flows, and visualized the collected data in a Power BI dashboard designed to meet national leadership needs. A bespoke Power App was designed for employee onboarding and monthly status updates data collection, which was stored on SharePoint Lists. The PowerApp and Power BI dashboard were embedded on a custom SharePoint page only accessible to onboarded employees.

Due to client IP restrictions, only images of the Power BI dashboard are displayed here. Some dashboard pages are broken into multiple images because of size limitations.
