EXCLAIM Executive Admin Dashboard

Description

Supported the rollout of a nationwide VA program by designing custom data entry, storage, and analytics solutions to help improve cancer treatment outcomes through the use of genetic testing and more targeted treatment selection.

Supported nationwide training rollout by developing registration and scheduling tools using Microsoft O365 applications including Outlook, Forms, SharePoint, Teams, Power Apps, and Power Automate. Integrated collected data into a Power BI dashboard designed to meet national leadership needs.

The custom Power App for employee onboarding and monthly status updates was underlaid by a SharePoint List, and both the Power App and Power BI dashboard were embedded on a custom SharePoint page accessible only to onboarded employees.

Due to client IP restrictions, only images of the Power BI dashboard are displayed here. Some dashboard pages are broken into multiple images because of size limitations.
