Clinical Cancer Genetics Service (CCGS)

A custom, multi-page Power BI Dashboard designed to support executive management of the nationwide rollout of preventative genetic testing program at the VA.

Back to Projects

Description

This project supported the national management's monitoring of the rollout the Clinical Cancer Genetics Service (CCGS), which helps participants understand if they have an inherited cancer risk. The custom dashboard connects to VA’s Corporate Data Warehouse (CDW), a Relational Database Management System (RDBMS) hosted on Microsoft SQL Server. It visualizes the amount and type of consultations and tests completed, which diagnostic labs tested samples, the location of VA medical facilities and the volume of testing being performed at those facilities, the type and frequency of diagnoses, the turnaround time from samples collected to tests performed, patient information, and scheduling availability of frontline care providers.

Applications Used

  • Power BI
  • Microsoft SQL Server
  • T-SQL
